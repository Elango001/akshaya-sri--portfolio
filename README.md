## 🎨 Design System & Architecture (Inspired by `mprogano.com`)

The portfolio implements the exact narrative cadence and component architecture of **mprogano.com**:

1. **Top Announcement Bar:** Subtle open-source / availability banner linking directly to connect.
2. **Floating Pill Navigation:** Clean brand wordmark, center anchors (*Home*, *Capabilities*, *Works*, *Approach*, *FAQs*, *Connect*), animated theme toggle (Light/Dark), and direct Resume PDF action.
3. **The Signature Hero:**
   - Giant display typography: **"I shape complex systems into tools people actually use."**
   - Action pills: *Ways to Connect* and *Go on.. ↓*
   - Personal intro card (*Hello 👋 I'm Akshaya...*) with the three core traits:
     - **Product Builder:** Works out what’s worth building, then builds hands-on.
     - **Technical Translator:** Connects user needs with machine learning models, APIs, and architecture choices.
     - **Detail-Oriented:** Designs interfaces with clear source attribution and edge-case recovery.
   - Quote endorsement block from academic mentors and hackathon judges.
4. **Capabilities ("Where I'm most useful"):**
   - *01. Build the tool you’re missing* (0-to-1 Prototypes like LocalLens AI and AI Fashion Advisor)
   - *02. Improve the system you rely on* (Workflow optimization like SONA Scheduler and Timber manufacturing operations)
5. **Selected Works ("What this looks like in practice"):**
   - The disciplined 4-part case study anatomy from mprogano:
     - **Context:** The real-world setting.
     - **What was needed:** The friction and core human insight.
     - **Work I did:** PRD scoping, technical architecture, and cross-functional execution.
     - **What Changed:** Verified quantitative metrics and learnings.
6. **Approach ("Working Together — From understanding to delivery"):**
   - *01. Understand the work*
   - *02. Choose a useful first version*
   - *03. Build and learn*
7. **Heuristics Grid ("How I think about software"):**
   - 6 practical rules for data clarity, intentional AI usage, repetitive workflow design, and defensive recovery.
8. **Interactive FAQs ("A few questions people usually ask"):**
   - Framer Motion accordion answering key product philosophy, domain experience, and leadership questions.
9. **Interactive Connect Form ("What are you trying to make work?"):**
   - Contact preference pills (*Email Me*, *LinkedIn*, *Call / Text*), input fields, personal reply guarantee, and direct communication channels.
10. **Dual Theme Engine:**
    - **Light Mode:** Warm soft grey ground (`#f2f4f7`), crisp white cards, dark navy/slate ink, and subtle radial dot grid.
    - **Dark Mode:** Deep midnight canvas (`#0e1017`), elevated graphite cards, soft off-white text, and muted borders.
